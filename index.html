How I work

I started with networking and Linux, then moved into cybersecurity: how attacks actually look in a log file, what makes a URL suspicious, and why weak passwords fail so fast. Each tool I build answers one of those questions in code — with clear output a non-expert can read.

In parallel I build AI automation agents in Python: small, honest tools that classify, summarise and draft — no invented answers, graceful fallbacks, and demo data clearly labelled as demo data. That discipline matters: an agent that admits what it doesn't know is one you can actually trust in a workflow.

I'm now looking for an internship where I can apply this on real systems — a security team, an automation project, or a web product — and keep shipping.
